# GymSaaS 🏋️‍♂️

Sistema de gestión multi-tenant de turnos y deudores para PyMEs (Gimnasios).

Este repositorio es el **proyecto conductor** de mi plan de formación en Ingeniería de Software. Está diseñado para dominar patrones de arquitectura, modelado de datos, APIs seguras y el desarrollo multiplataforma con Kotlin (KMP).

## 🛠️ Stack Tecnológico (en progreso)
*   **Lenguaje:** Kotlin 2.x (JVM)
*   **Base de Datos:** PostgreSQL (Próximamente)
*   **Backend:** Ktor (Próximamente)
*   **UI:** Compose Desktop (Próximamente)
